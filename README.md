# 彩票助手 LotteryAssistant

一款使用 **SwiftUI** 与 **SwiftData** 开发的 iOS 彩票记录与开奖核验工具，当前支持双色球与超级大乐透。

> 本应用仅用于号码记录、开奖查询、中奖核验和历史数据浏览，不提供购彩、支付、兑奖或任何提高中奖概率的预测服务。中奖金额与兑奖结果请始终以官方当期公告为准。

## 功能

- **开奖查询**：浏览双色球、超级大乐透的历史开奖期次、号码、开奖日期、奖池与数据来源。
- **官方数据同步**：
  - 双色球优先直连中国福利彩票官网。
  - 超级大乐透优先直连中国体育彩票官网。
  - 官网请求失败时，回退至 [`yangxb919/lottery-data`](https://github.com/yangxb919/lottery-data) 开源镜像。
- **彩票录入**：支持手工选择号码、开奖期号、倍投和大乐透追加投注。
- **OCR 票据识别**：支持相机拍摄或从相册导入票据图片；识别结果必须人工确认后才会写入彩票。
- **中奖核验**：按双色球六级奖与大乐透七级奖规则核验前区/后区命中数。
- **奖金估算**：使用官网当期奖级金额，计算倍投及大乐透一、二等奖追加后的预计奖金；镜像数据缺少奖级金额时会显示“待确认”。
- **票据管理**：管理待开奖、未中奖、已中奖、已兑奖的彩票，并查看投注金额、命中号码和预计奖金。
- **随机选号与账本**：随机生成合法号码，查看已保存票据数和累计投入。

## 快速开始

1. 克隆仓库：

   ```bash
   git clone git@github.com:liu6x6/LotteryAssistant.git
   cd LotteryAssistant
   ```

2. 使用 Xcode 打开 `LotteryAssistant.xcodeproj`。
3. 选择 iOS 26.2 或更高版本的模拟器/真机并运行。
4. 在 App 的**开奖中心**点击右上角刷新按钮同步开奖数据。

首次同步会获取完整历史记录：双色球最多 2078 期，大乐透需要分页获取历史数据，因此耗时会比后续刷新更长。后续刷新只拉取官方最近数据。

## 数据源与同步策略

| 彩种 | 主数据源 | 兜底来源 | 说明 |
| --- | --- | --- | --- |
| 双色球 | 中国福利彩票官网 | GitHub 镜像 | 官方接口提供开奖号码、奖池及当期奖级金额 |
| 超级大乐透 | 中国体育彩票官网 | GitHub 镜像 | 官方接口提供开奖号码、奖池、七级奖金额及追加奖金额 |

同步时会执行以下保护：

- 双色球期号统一为 7 位 `YYYYNNN`，大乐透期号统一为 5 位 `YYNNN`。
- 校验号码数量、号码范围和同区重复值，不合法数据不会写入 SwiftData。
- 已存在的开奖记录不会重复插入；官方数据会补全镜像数据缺失的奖池和奖级金额。
- 同步完成后会自动重新核验尚未兑奖的彩票。

建议在开奖日 **23:35 后**刷新，使大乐透奖池与奖级数据有时间完整发布。

## OCR 使用说明

1. 新建彩票，点击“扫描或导入票据”。
2. 使用相机拍摄，或从相册选择一张号码清晰的票据照片。
3. 在确认页面核对和修改期号、前区/红球、后区/蓝球。
4. 只有通过号码数量、范围和去重校验后，才能应用识别结果。

OCR 在设备本地通过 Vision 处理，图片与识别文本不会上传至应用服务器。模拟器不支持相机拍摄，请使用相册导入或真机测试相机功能。

## 当前限制与后续计划

- 目前仅支持单式票录入；复式、胆拖、多期票尚未实现。
- 彩票原始照片、门店、购买备注尚未持久化。
- 未实现开奖、中奖和兑奖期限的本地通知。
- 未实现 iCloud/CloudKit 同步、数据导出和备份恢复。
- 统计页当前只包含基础账本；冷热号、遗漏、分布和趋势分析待完善。
- GitHub 镜像仅用于兜底和补充历史；正式发布前请确认第三方数据仓库的许可与使用条件。

- 彩票开奖结果是随机事件；历史统计和随机选号仅供娱乐，不能提高任何号码组合的中奖概率。
